UniWebView · AppsFlyer / Facebook 集成测试

通过 uniwebview://{action}?requestId=… 发送请求；Unity 使用 window.onUnityMessage(object) 回调。 所有请求串行执行，每次等待最多 8 秒。普通浏览器没有原生桥时会超时，不会模拟成功。

Editor 事件返回 ok:false / sdk_unavailable_in_editor；原生接收成功也不代表分析平台已收到事件。

2. 外部链接 · openURL

3. 发送数据 · sendData

4. AppsFlyer 事件 · onEventJs

每个键以 cp. 前缀发送；不要与 params 中的键重复。填写 revenue 时须提供 currency。

5. Facebook 事件 · onFacebookEvent

6. 归因与集成状态

归因回调：type=appsflyer，info 为原始归因对象并包含 appsflyer_id；requestId 按请求回传。

自动测试

仅点击下方按钮或本次显式测试驱动才执行，打开/刷新页面不会自动运行。会切换方向，并发送两条 AF、一条 FB 的 integration_bridge_test 测试事件（均不含金额）；不代表后台入库。旧 autorun 参数不再生效。此页面无法读取原生方向锁定和自动旋转掩码，套件结束后须由外部驱动恢复原状态；桥接 PASS 不表示恢复完成。
