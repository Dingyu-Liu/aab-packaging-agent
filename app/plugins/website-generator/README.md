# 官网与隐私生成模块

模块 ID：`website-generator`，类型：`website`，版本：`0.1.0`。

在工作台左侧「官网与隐私」使用。已有官网、已有隐私链接、关键词或描述均为选填，三者至少填一项。生成目标可选择官网、隐私政策或两者。

每次生成一个包含 `index.html`、`privacy.html` 和 `styles.css` 的独立静态工程。单选时自动附带另一配套页，保证工程内的两个页面相互跳转。提供的外部页面作为参考资料，不修改原站点。

生成说明位于 `scripts/generation-prompt.txt`，可通过「仓库管理」更新。新任务冻结当前模块清单、生成说明、摘要与模型配置；既有工程不随更新改变。内容渲染、链接连接、预览隔离与文件下载由应用固定代码完成。

复用本机模型配置和任务记录。此模块不需要本地 Android/Unity 工程，也不启动 SDK 接入或业务数据同步。

本版提供本机预览链接和 ZIP 工程下载。公开网址需要把完整工程部署到静态网站托管服务。具体使用和边界见 `docs/website-generation.md`。
