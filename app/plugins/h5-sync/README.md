# 受控真实 H5 同步模块

包装版本0.3.1。来源是本机发现、用户授权本任务参考的H5更新助手.zip内真实Python脚本，原始源哈希与派生版本哈希见provenance.json；用户资产归属与原作者权利保留，不宣称获得额外开源授权。

插件内不保存固定业务标识、收件人、群ID或本机启动路径。来源表格和配置表默认读取应用根目录的私有 h5.config.local.json；也可使用部署环境变量或本轮高级参数覆盖。产品到目标分表的映射始终读取飞书配置表。日常更新仅需选择日期，批量更新使用相同默认配置。配置文件不会随插件发布或被脚本更新覆盖。参数与完整接入契约见应用docs/h5-integration.md。

只保留online fetch-source、fetch-config、scan、sync入口；原run、expand、卡片和消息入口不使用且已从派生CLI移除。预演只读远程、不写飞书、不发消息；正式模式只有通过全部来源/目标/日期行预检后才允许csv-put。写入后逐条解析回读，证据不足保持待核对。

缺数值不回退0、缺来源不补0、重复配置/来源/日期不静默取最后项、expiring不猜行号。任务JSON与原始输出仅保存在当前任务独立私有目录，UI只接收摘要，不透传包含资源标识的sample任务。
