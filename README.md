# aab打包智能体

**AAB助手**：基于 Partner Agent 0.1.21 整理的免登录 macOS 桌面软件，采用深蓝色横向操作台，主要用于检查 Android / Unity 导出工程、处理编译问题，并在编译通过和用户确认后生成 Release AAB。保留原有 SDK 接入、数据同步与网站生成模块。

## 下载与安装

**[下载完整 macOS 软件包](https://github.com/Dingyu-Liu/aab-packaging-agent/releases/latest/download/AAB-Assistant-macOS.zip)** · [查看发行版本](https://github.com/Dingyu-Liu/aab-packaging-agent/releases)

1. 下载 `AAB-Assistant-macOS.zip` 并解压。
2. 将其中的 `AAB助手.app` 拖入“应用程序”，双击打开；无需本软件账号。
3. 若下载隔离标记阻止启动，保存工作并退出主应用，再使用同包的 `修复 AAB助手 启动.app`。备用脚本为 `partner-agent-fix.sh`。
4. 打开“设置”，配置自己的模型服务，然后进入“GP打包”选择工程、填写版本、开始编译，编译通过后确认生成 AAB。

**直接运行一次修复脚本：** 在终端输入 `/bin/sh`，加空格，拖入 `partner-agent-fix.sh`；再加空格，拖入 `AAB助手.app`，按回车。完成后直接打开主应用。[使用教程](docs/USER_GUIDE.md)提供逐步说明和常见报错处理。

完整软件包包含主应用、全部内置运行组件和技能模块、双击启动修复工具、备用脚本及中文文档。ZIP 内的应用名称保持中文，路径支持中文与空格。

> 请从 Releases 下载完整 ZIP。“Code → Download ZIP”只下载可浏览代码与文档，不是可运行的安装包。

## 界面与工作流程

顶部横向导航切换各模块；“GP打包”上方配置工程和版本，标题右侧开始编译。下方左侧显示历史记录，右侧查看进度、对话、构建日志和产出文件。编译通过后，标题右侧提供确认与取消操作。

工作流程：选择完整工程 → 检查参数与环境 → 编译及处理问题 → 用户确认 → 生成 Release AAB → 下载产物。

取消了软件登录和账号权限限制。模型服务仍需用户自己的配置；打包确认、签名校验及本机请求保护继续生效。

## 平台范围

当前发行包仅支持 **macOS**，以 macOS 13 或以上为使用基线。内置运行组件为 Intel x86_64；Apple 芯片 Mac 需要 Rosetta 2。未完成所有机型的实机验收。

Windows 不能直接运行本包的 Mac 可执行文件。内置模型引擎、桌面入口、部分工具链准备及 Unity IL2CPP 资源仍依赖 macOS；保留的 iOS 构建流程也依赖 Xcode。完整说明及 Windows 适配所需工作见[发行说明](docs/DISTRIBUTION_README.md)。

| 位置 | 内容 |

## 验证范围

已验证免登录初始化、设置读写、模块刷新、主要界面操作、确认与取消、记录切换、日志与下载链接，并检查修复脚本、应用签名和压缩包完整性。后端任务处理逻辑和技能模块在本次界面改版中保持不变。

尚未以真实目标工程完成端到端 AAB 构建，也未完成所有模块的完整业务流程或其他 Mac 机型验收。应用使用本地临时签名，未做 Apple 开发者签名与公证。

个人模型配置、任务记录、签名密钥和工程目录不包含在公开发行包中。换电脑后需重新配置模型、选择工程，并准备对应工具链与原签名材料。
